# Azure Setup Guide for Agentic Logic App & Function Deployment

This guide walks you through deploying the Agentic Logic App and Azure Functions for the CopilotFlow
agentic code review workflow. It includes all required Azure resource details and step-by-step
instructions.

---

## Prerequisites

- Azure Subscription ID: `c11e8155-3f4f-4cb0-8ab3-3d31e4524e1c`
- Resource Group: `CopilotFlow`
- Location: `westus3`
- Azure CLI installed and logged in
- .env file configured (see `.env.example`)

---

## 1. Create Resource Group (if not exists)

```pwsh
az group create --name CopilotFlow --location westus3
```

## 2. Create Azure Function App

Choose a globally unique name for your Function App. Example:

- Function App Name: `copilotflow-agentic-func`

```pwsh
az functionapp create --resource-group CopilotFlow --consumption-plan-location westus3 --runtime node --functions-version 4 --name copilotflow-agentic-func --storage-account <yourstorageaccount>
```

- Replace `<yourstorageaccount>` with a unique storage account name (create with
  `az storage account create`).

## 3. Deploy Azure Function Code

```pwsh
az functionapp deployment source config-zip --resource-group CopilotFlow --name copilotflow-agentic-func --src docs/azure-function-analyze-code.js
```

## 4. Create Logic App

Choose a name for your Logic App. Example:

- Logic App Name: `copilotflow-agentic-logicapp`

```pwsh
az logicapp create --resource-group CopilotFlow --location westus3 --name copilotflow-agentic-logicapp
```

## 5. Deploy Logic App Workflow

```pwsh
az logicapp deployment create --resource-group CopilotFlow --name copilotflow-agentic-logicapp --definition docs/logic-app-agentic-workflow.json
```

## 6. Update .env Configuration

Add the following to your `.env` file:

```
AI_PROVIDER=Azure OpenAI
AZURE_OPENAI_ENDPOINT=https://<your-azure-openai-endpoint>
AZURE_OPENAI_API_KEY=<your-azure-openai-api-key>
AZURE_OPENAI_API_VERSION=2023-05-01
AZURE_OPENAI_DEPLOYMENT_NAME=<your-deployment-name>
OPENAI_API_KEY=<your-openai-api-key>
AI_MODEL=gpt-4
AZURE_FUNCTION_ANALYZE_CODE_URL=https://copilotflow-agentic-func.azurewebsites.net/api/analyze-code
AZURE_FUNCTION_QA_REVIEW_URL=https://copilotflow-agentic-func.azurewebsites.net/api/qa-review
AZURE_FUNCTION_UPDATE_DOCS_URL=https://copilotflow-agentic-func.azurewebsites.net/api/update-docs
AZURE_FUNCTION_GENERATE_TESTS_URL=https://copilotflow-agentic-func.azurewebsites.net/api/generate-tests
DEVELOPER_AGENT_CONNECTION=<connection-name>
QA_AGENT_CONNECTION=<connection-name>
```

- Replace placeholders with your actual values.

## 7. Validate Deployment

- Check Azure Portal for Function App and Logic App status.
- Test Logic App trigger and workflow.
- Run `npm run ai:generate-docs` to validate documentation updates at each review loop.

## Notes

- Function App and Logic App names must be globally unique.
- Storage account is required for Function App.
- Update Logic App workflow file with actual URLs after deployment if needed.
- Use `.env.example` as a template for your configuration.
