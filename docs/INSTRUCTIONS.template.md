# 📖 CopilotFlow Instructions Template

This template provides the structure for personalizing your CopilotFlow instructions. Copy this file
to `INSTRUCTIONS.md` and edit with your personal information, stylistic preferences, and workflow
details.

--

## 🚦 How to Use This Template

1. **Copy this file** to `INSTRUCTIONS.md` in your project root.
2. **Edit all fields** below with your personal information, stylistic preferences, and workflow
   details.
3. **Save and update** `INSTRUCTIONS.md` as your workflow or project context evolves.
4. **Do not check in** `INSTRUCTIONS.md` to version control; keep it personal and project-specific.
5. **Reference your instructions** in onboarding docs and Copilot prompt files for consistent AI
   guidance.
6. **To use your instructions with Copilot:**
   - Copy the contents of your updated `INSTRUCTIONS.md` and paste them into your Copilot session or
     prompt file as context.
   - For more details on using custom instructions and context, see the
     [VS Code Copilot Custom Instructions documentation](https://code.visualstudio.com/docs/copilot/copilot-customization#_custom-instructions).
